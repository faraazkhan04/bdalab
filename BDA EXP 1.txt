Step 1: Create a Working Folder
Open PowerShell.	
mkdir C:\bda-lab
cd C:\bda-lab
________________________________________
Step 2: Create the Dockerfile

Create a file named Dockerfile inside C:\bda-lab.

Paste the following code:

FROM ubuntu:22.04

ENV DEBIAN_FRONTEND=noninteractive

RUN apt-get update && apt-get install -y \
    openjdk-8-jdk \
    wget \
    nano \
    vim \
    ssh \
    rsync \
    net-tools

ENV JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
ENV PATH=$JAVA_HOME/bin:$PATH

RUN wget https://dlcdn.apache.org/hadoop/common/hadoop-3.4.2/hadoop-3.4.2.tar.gz && \
    tar -xzf hadoop-3.4.2.tar.gz && \
    mv hadoop-3.4.2 /opt/hadoop && \
    rm hadoop-3.4.2.tar.gz

ENV HADOOP_HOME=/opt/hadoop
ENV PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin

CMD ["/bin/bash"]

Save the file.
________________________________________
Step 3: Build Docker Image
docker build -t bda-hadoop .
________________________________________
Step 4: Start Hadoop Container
docker run -it --name hadoop bda-hadoop

________________________________________
Step 5: Verify Installation
java -version
javac -version
hadoop version
________________________________________
Step 6: Create WordCount.java
nano WordCount.java
Paste the Java program supplied in your lab manual.
Save
Ctrl + O
Enter
Ctrl + X
________________________________________
Step 7: Create Input Folder
mkdir input
________________________________________
Step 8: Create Input Files
echo "the quick brown fox the lazy dog the fox" > input/file1.txt
echo "a quick dog and a brown fox jumped" > input/file2.txt
Verify
cat input/file1.txt
cat input/file2.txt
________________________________________
Step 9: Set Hadoop Classpath
export HADOOP_CLASSPATH=$(hadoop classpath)
________________________________________
Step 10: Create Classes Directory
mkdir classes
________________________________________
Step 11: Compile the Program
javac -classpath "$HADOOP_CLASSPATH" -d classes WordCount.java
No errors should appear.
________________________________________
Step 12: Create JAR File
jar -cvf wordcount.jar -C classes .
________________________________________
Step 13: Execute Word Count
hadoop jar wordcount.jar WordCount input output
________________________________________
Step 14: Display Output
cat output/part-r-00000
Output
a       2
and     1
brown   2
dog     2
fox     3
jumped  1
lazy    1
quick   2
the     3
________________________________________
Step 15: Execute Again
Delete previous output.
rm -rf output
Run again.
hadoop jar wordcount.jar WordCount input output
________________________________________
Step 16: Exit
exit
Stop the container.
docker rm -f hadoop
